## Universal Downloader v1.0.0

First stable release.

### What is in 1.0.0

- **Reliable extractors.** Platform adapters (TikTok, Instagram, Spotify/Apple, generic
  yt-dlp) with typed error codes, captured-payload regression tests, a platform health
  check and copyable redacted diagnostics.
- **Working updater.** The app checks, downloads and installs updates, with a download
  timeout and a confirmation dialog that states running downloads will stop.
- **Updatable extractor.** yt-dlp can be refreshed without shipping a new installer; the
  user copy is validated and a broken one is quarantined instead of breaking startup.
- **History, queue and notifications.** History is stored by the app, records failures,
  and never deletes your files when you delete an entry. `Retry failed (N)` retries a
  whole batch. Notifications cover success, failure and sign-in-required (deduplicated).
- **CI and release guard.** PR checks run the backend, frontend and desktop suites.
  `npm run verify-release` refuses inconsistent metadata, stale checksums, a mismatched
  notes table, or a `backend-engine.exe` older than the backend source.
- **Docs.** Cookie setup, troubleshooting mapped to every error code, diagnostics, and a
  size analysis.

## Universal Downloader v0.7.1

Hardening release. First version that can install its own updates.

### Fixes and hardening

- **Auto-update now installs.** Settings → App updates gained an **Install update** action: the app downloads the release, quits into the installer and relaunches. Before this, the app could only report that a new version existed.
- **Regression safety net:** 18 new tests (backend suite 134 → 152). Captured, sanitized fixtures for TikTok Photo Mode, Instagram embed/login wall and Spotify metadata now run offline.
- **Audio gating matrix:** mp3 / m4a / opus / lossless × social bypass × Spotify / Apple Music / YouTube-music / search queries, so an audio job can never come out as `.mp4`.
- **Release guard script:** `npm run verify-release` fails the build if `latest.yml`, artifact names, sizes, SHA-512, version strings or this notes table disagree.
- **Checksums are UTF-8** (`SHA256SUMS-0.7.1.txt`), so `sha256sum -c` works outside Windows.

### Updating

- **From 0.7.0: manual, once.** 0.7.0 shipped without the install bridge, so it can only tell you 0.7.1 exists. Install this release by hand.
- **From 0.7.1 onward: should be automatic.** Tested end-to-end on the packaged 0.7.1 build against a local feed advertising 0.7.2: the app fetched `latest.yml` → `.blockmap` → installer, quit, installed and relaunched. The payload in that test was the 0.7.1 installer, so the version number itself did not change; a real 0.7.1 → 0.7.2 upgrade has not been observed yet.
- The update installs as soon as you click **Install update**; it does not wait for active downloads to finish.

### Notes

- Builds are **not code-signed**. Windows SmartScreen may warn: *More info → Run anyway*.
- Requires Windows 10/11 x64. Python, FFmpeg and the UI are bundled.

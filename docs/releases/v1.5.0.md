# Universal Downloader v1.5.0

Draft release notes. The installer, portable ZIP, update manifest, and SHA-256 table are
filled in by the release build.

## What's new since v1.0.0

### Desktop

- **Beta update channel.** A version containing `-beta` builds `beta.yml` and publishes as
  a GitHub prerelease; stable clients stay on `latest.yml`. `electron-updater` enables
  prerelease checks only for a client whose own version has a prerelease tag.
- **Engine version guard.** The packaged backend exposes `APP_VERSION` and the release
  workflow writes `desktop/backend-engine/app-version.txt`. `verify-release` fails when
  the engine stamp is missing or disagrees with the backend/release version.
- **Active-job update warning.** Installing an update reads the live queue from
  `GET /api/queue` and tells the user how many running downloads will stop.
- **Updater harness.** `desktop/e2e/update.test.js` covers check -> available -> download
  -> install -> relaunch against a local feed, plus no-update and error paths.
- **Version label.** The sidebar, Settings, and diagnostics read the version from
  `frontend/package.json` instead of the stale hardcoded `1.0.0`.

### Extractors

- **TikTok `embed/v2`.** Captured a real embed payload for the photo-post fallback; the
  fixture is trimmed and its signed query values are redacted.
- **Spotify cover art.** The `visualIdentity.image` fallback is covered by unit and
  captured-fixture tests (fixed before v1.0.0, now recorded in the backlog).
- **Wheel updater hardening.** yt-dlp wheel updates have a 5-minute total deadline,
  cancellation support, and `yt_dlp.backup` crash recovery on startup or before an install.

### Android (pre-release)

- Native Android app shipped as `android-v1.0.0` (debug-signed pre-release).
- Kotlin + Jetpack Compose, youtubedl-android 0.18.1, MediaStore saves, SQLite history,
  foreground downloads, cookies import, Spotify bridge, English/Thai UI.
- Known limits: one link at a time, no pause, no playlists/photo posts/carousels, an
  in-memory queue, and a debug signature that requires an uninstall before a future
  signed build.

## Release status

The tag workflow builds the installer, portable ZIP, `latest.yml`, and
`SHA256SUMS-1.5.0.txt` in one run and attaches them to the GitHub release. No hashes are
committed here; verify the attached SHA256SUMS file against the downloaded assets. The
installer is unsigned, so SmartScreen may warn. The release stays a draft until the
artifacts and hashes are checked.

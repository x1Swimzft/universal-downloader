## Universal Downloader v0.8.0

Extractor reliability and updater hardening.

### Extractors

- **Split into platform adapters.** Spotify/Apple Music, TikTok, Instagram and the shared
  yt-dlp pipeline now live in `backend/app/services/adapters/`, behind a registry and a common
  interface. `extractor.py` keeps its public API, so nothing else changed.
- **Two new error codes:** `LINK_EXPIRED` and `PLATFORM_CHANGED`, so a broken site layout is
  reported as "the site changed, update the app" instead of a generic failure.
- **Platform health check:** Settings â†’ **Test platforms** probes TikTok, Instagram and YouTube
  without downloading anything and reports pass/fail, error code and duration per platform.
- **Copy diagnostics:** Settings â†’ **Copy diagnostics** copies app, OS, Python and extractor
  versions plus the last health result. Signed URL values, token headers and your Windows
  username are redacted before anything is copied.
- **Spotify cover art fixed.** Cover images were always missing because the parser only read
  `coverArt`, while Spotify now serves artwork under `visualIdentity.image`.

### Extractor updater

- **Import order fixed:** a freshly installed extractor wheel now takes effect in the same
  process instead of only after the next start.
- **A corrupt extractor copy can no longer break startup.** The user copy is validated, and a
  broken one is renamed to `yt_dlp.broken-<timestamp>` with the bundled copy used instead.
- **Wheel downloads are checked against PyPI's SHA-256** before installation.

### App updater

- **Download timeout** (10 minutes) so a stalled update no longer leaves the button spinning.
- **Confirmation before installing**, stating that running downloads will stop.
- **The window now gets the result** before the app quits, instead of a spurious failure.
- The install flow is covered by unit tests (`npm test` in `desktop/`).

### Updating

- **From 0.7.1: automatic.** Settings â†’ App updates â†’ Check for updates â†’ Install update.
- **From 0.7.0 or older: manual, once**, then automatic from 0.8.0 onward.
- Installing the update closes the app; any running download stops.

### Notes

- Builds are **not code-signed**. Windows SmartScreen may warn: *More info â†’ Run anyway*.
- Requires Windows 10/11 x64. Python, FFmpeg and the UI are bundled.

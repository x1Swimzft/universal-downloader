## Universal Downloader v0.9.0

History, queue and notification polish.

### History

- **One history, stored by the app.** The History tab now reads the backend's history file
  instead of a browser-side copy, so entries survive restarts, updates and profile changes.
  Existing local entries are still shown when the backend store is empty.
- **Failed downloads are recorded**, marked **Failed**, and keep their error code. Entries
  without a `status` field (anything written by 0.8.0 or earlier) are treated as completed.
- **Deleting a history entry never deletes the file.** It only removes the record; the media
  stays where it was downloaded.
- Search by title/URL, media and platform filters, open folder, re-download and clear-all keep
  working as before.

### Queue

- **Retry failed (N)** retries every errored item in one click.

### Notifications

- Desktop notifications now fire on **failure** as well as success.
- **Sign-in required** is deduplicated per error code with a 60 second cooldown, so a batch of
  gated links produces one notification, not one per item.

### Compatibility

- History JSON gains additive `status` and `error_code` fields. Older builds ignore them; this
  build treats missing fields as completed.
- Updating from **0.8.0 is automatic** (Settings â†’ App updates). 0.7.0 and older still upgrade
  manually once.

- Requires Windows 10/11 x64. Python, FFmpeg and the UI are bundled.
